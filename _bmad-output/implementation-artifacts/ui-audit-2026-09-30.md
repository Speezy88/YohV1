# Yoh — UI audit (2026-09-30)

Why: Spencer — "it doesn't look as professional and complete as it could", cause not pinned down.
Feeds: `sdd-plan-YohV1-polish-6.md` (same folder).

## Method and limits

Four lenses: Vercel Web Interface Guidelines code pass; rendered screenshots (fixture server, light + dark, 1440 / 1024 / 768 / 390 wide); state-completeness matrix; visual-consistency inventory.

- **The audit ran on branch `epic13-planning`, which is behind `main`.** Files that differ on `main` (ChatMessage, ChatPanel, UndoToast, StructuredQuestion, PageShell, Sidebar, tokens.css) were re-checked before anything was fixed. **The Memory page and its components (`web/src/pages/Memory.tsx`, `web/src/components/memory/*`, RatingPrompt, RememberedReceipt) were not audited.**
- Line numbers below are from the audited branch; anchor on names.
- `?` = read from code, not confirmed in a render.
- The raw per-line reports and screenshots lived in a session scratch folder that was removed; this file is the surviving record. The 57 lowest-severity Vercel findings are kept as patterns, not line by line.

## Verdict

The foundation holds: dark mode is consistent, colours/radii/shadows are fully tokenised (0 hard-coded colours in components), task-row truncation, Tasks/Research skeletons and write-failure toasts are handled well. The unfinished feeling comes from seven gaps.

## Findings, ranked

### 1. Nothing responds to the pointer
- 0 `transition-colors`, 4 `transition-*` uses in all of `web/`; every hover/press/selection snaps.
- 0 `active:` states; hover on roughly 14 of 36 buttons (pre-Memory count), mostly a text-colour swap; 2 `cursor-pointer`.
- No hover at all on: Ask Yoh pill, MiniMonth days and arrows, Time Budget pill, Command Palette rows, Theme Toggle, Checkbox, Structured Question chips, Reshuffle Approve/Discard, Undo, chat Send.
- No `focus-visible` style (browser default ring only) on: Sidebar nav + arrows, ChatPanel chip/Close/Jump, Ask Yoh pill, Theme Toggle, MiniMonth, Time Budget Save/Cancel, NotificationOverlay card + Dismiss. The files that do style focus share one 2px accent outline, duplicated as a local `FOCUS` constant in ~8 files.

### 2. Empty, loading and error states are one grey line
- Load errors (Home, Tasks, Research Hub) use the same grey body text as empty states; no icon, no button. One Retry exists in the app (another day's calendar).
- A failed Home refetch replaces a loaded page with the error line (`lib/homeView.ts`); Tasks and Research keep stale data.
- Chat opens to a blank stream. A finished Plan is one line in a large card. Today's empty calendar shows nothing (other days say "Nothing on the calendar"). Month view marks nothing on any day.
- Desk is a nav page reading "Desk — coming in a later epic."
- Home skeleton has no header/cards, so the page jumps on load.
- Command Palette shows "No matching command" while loading, and permanently after one failed fetch (`lib/commands.ts` caches `[]`).
- Tasks: zero results under the Missing data filter shows "No Tasks yet". TaskQuickAdd: a failed preview silently shows no chips.
- Server strings rendered raw `?`: `{state.message}` in Tasks/Research errors, `errorText` in ChatMessage.

### 3. The layout only works above ~1300px
0 `sm:`/`md:`/`lg:` classes. Fixed: Sidebar `w-[248px]`, Home `grid-cols-[minmax(0,1fr)_520px]`, ChatPanel `left-[268px]`, `TASK_ROW_GRID` (~800px of fixed columns). Rendered: at 1024 the Plan card collapses under the Time Budget pill; at 768 task titles disappear; at 390 content is cut off and the Ask Yoh pill sits on the Theme Toggle. The experience spec lists "Narrow windows / phone" as not specified. Spencer (2026-09-30): not used on a phone today, but planned.

### 4. Controls don't share a system
- ~12 control heights (26, 28, 30, 34, 38, 40, 42, 44, 46, 50, 54, 58px).
- Primary buttons: three radii (full in SandboxCard, md in ReshufflePreviewCard, sm in TimeBudgetWidget), two heights, three disabled opacities (40/50/60). DESIGN.md says `button-primary` and `button-secondary` are `rounded.sm`.
- SandboxCard uses browser-default date and select inputs.
- 19 inline SVGs with 5 stroke widths; 7 of 17 follow the 1.8px rule (2.4px used 6 times). Chevron, pin and search glyphs are duplicated across files.
- z-30 is shared by the chat panel, Ask Yoh pill and confetti.

### 5. Spacing and type are subtly off
- `tokens.css` defines spacing steps 5 and 6 as 24px and 32px, so `p-6` (32) is larger than `p-7` (28) and `gap-6` > `gap-7`; `size-5` is 24px while `PIN_SIZE_PX = 20` assumes 20 `?`.
- Home Plan card `p-7` beside Calendar card `p-5`; big surfaces `rounded-xl` (Tasks, Research) vs `rounded-2xl` (Home); a 28px-radius card nested in a 28px-radius card (ReshufflePreviewCard).
- Gap under page titles: 24 / 18 / 22px on Home / Tasks / Research. 18px written both as `px-[18px]` (7) and `px-4.5` (3). ~45 arbitrary-value utilities in total.
- Only Figtree 500 and 700 are loaded; `font-semibold` and `font-normal` collapse to those.
- Real content at `text-caption` (10.6px) and `text-label` (11.5px): SandboxCard error + labels, PlanChecklist markers, TaskRow, NotificationOverlay.
- Row heights 64 / 58 / ~74. In light mode `surface-base` equals `surface-raised`, so card edges rely on shadow alone.
- Typography nits (pattern): straight quotes/apostrophes in copy; no `tabular-nums` on numeric columns; no `text-wrap: balance`.

### 6. Visible glitches
Fixed in batch 1 (see below) except: a pale highlight band above the top card on Desk/Research (the extruded-lg light shadow, clipped at the page edge); AskYohPill centres on the viewport, not the content column.

### 7. Writes, focus and correctness
- A successful task edit shows no visible confirmation (a `saved` override state exists in Tasks.tsx but is not rendered; the receipt is `sr-only`).
- Time Budget: invalid input is silently ignored; Save only dims while saving.
- An SSE drop yields one never-cleared toast; no persistent connection indicator.
- Page state is not in the URL (`PageShell` `useState`): reload lands on Home, Back leaves the app. Tasks group-by/search and Home's shown date likewise.
- Accessibility: no `<main>` landmark or skip link; ChatPanel is `aria-modal` but the Sidebar stays interactive and there is no focus trap; `aria-activedescendant` on a plain textarea (no combobox role); NotificationOverlay card is `role="button"` containing real buttons; ThemeToggle's `aria-label` omits its visible text; MiniMonth today lacks `aria-current`, weekday letters lack names; Undo Toast gets no focus move; hit targets of 17–28px (Home checkbox, unpin, day-nav arrows, notification Dismiss); PlanChecklist label is not part of the checkbox target.
- Not rendered-verified: NotificationOverlay (top-right, z-40) covering the chat panel's Close button.
