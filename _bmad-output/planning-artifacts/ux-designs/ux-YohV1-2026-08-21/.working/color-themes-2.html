Yoh — Blue Gradient Accent Options (Round 2)

Four blue-gradient accent registers laid over the ROUND 1 material the user picked -- Variation 1, "Neumorphism-forward": warm off-white, soft extruded/inset neumorphic cards, a 1.5px hairline rim carrying every interactive boundary, glass reserved for floating elements only. The gradient is an accent, full stop -- it never becomes a page background or a card surface. Inspiration named by the user: Meta's Muse and Apple's apps, "high-tech but minimalistic," cool transitions "without it being too much." Both light and dark mode are shown for every option, side by side.

Wordmark note: "Yoh Meeseek" requested in bold Montserrat, declared as font-family: Montserrat, system-ui, sans-serif with no network load, so it renders in the system UI font here.

Non-color cues, still in force (WCAG 1.4.1 -- never color alone): the checked task gets a checkmark glyph + strikethrough + reduced opacity, not just a color swap; the fixed calendar block is cross-hatched and labeled "(fixed)"; the in-drag block is labeled "(dragging, from 2:00)" and outlined, not just tinted; the active nav item and active icon both carry the gradient fill AND full opacity vs. the inactive items' reduced opacity; Approve is always solid-filled, Discard always outline-only.

How the gradient is scoped per option: the full two-stop sweep appears only on surfaces that never carry text -- the reshuffle drag outline, the active nav pill, the "Thinking…" shimmer, the gradient icon stroke, and the toast accent bar. The Approve button and the checked checkbox clamp to one solid stop ("accent-solid") with a text color chosen to clear 4.5:1 -- see each option's handling note.
