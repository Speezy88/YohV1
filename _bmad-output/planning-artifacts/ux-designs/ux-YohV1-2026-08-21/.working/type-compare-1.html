Yoh — Type Comparison: Proxima Nova & Free Lookalikes

Answering: “what would the UI look like using Proxima Nova as the font?” Proxima Nova (Mark Simonson Studio) is a commercial webfont distributed through Adobe Fonts / Fonts.com — it is not installed on this machine and not on Google Fonts, so it cannot render here without an active paid license. Four panels below hold everything else constant — Round 1’s neumorphism-forward material, Round 2’s Sky→Azure accent, the same Home-page content, both light and dark — and change only the body/UI typeface, so the choice can be judged on its own.

Wordmark: “Yoh Meeseek” stays bold Montserrat in every panel (PRD FR-45/46, already decided) so body copy is judged against it, not swapped along with it.

Network exception, scoped to this file only: a Google Fonts <link> loads Figtree, Mulish and Montserrat — the three free lookalikes/decided wordmark face used below. No other network calls, no JS, no emoji.

Non-color cues still in force: checked task = checkmark glyph + strikethrough + reduced opacity; fixed calendar block = cross-hatch + “(fixed)” label; dragging block = outline + “(dragging, from…)” label; Approve solid-filled, Discard outline-only; active page-dot elongated + gradient-filled, not just recolored.

1 · “Proxima Nova”

font-family: "Proxima Nova", "proxima-nova", "Figtree", sans-serif;
Rendering: real Proxima Nova only if activated locally via Adobe Fonts — not the case on this machine, so you are seeing Figtree as a stand-in.

Why Figtree: the specimen (imports/proxima-nova-specimen.png) shows a geometric-humanist hybrid — near-round bowls on O/C/G, open apertures on c/e/s, a simplified single-story-reading lowercase, and grotesque-flavored numerals. Of the free faces tested (Figtree, Mulish, Inter, Jost), Figtree matched the specimen’s x-height, stroke-contrast (near-zero) and terminal openness most closely — it reads as the least-compromised free substitute, though its curves are slightly rounder/softer than Proxima Nova’s.

Wordmark pairing: Montserrat Bold over Figtree body — both are geometric-humanist sans faces, so the wordmark reads as intentionally heavier/branded rather than a clash. Of the four panels, this is the closest a free face gets to how the real Proxima-Nova UI would actually pair with the wordmark.

2 · Mulish

font-family: "Mulish", sans-serif;
Rendering: real Mulish, loaded from Google Fonts (free, SIL OFL).

Figtree already stood in for Proxima Nova in Panel 1, so this panel shows the next closest free lookalike: Mulish (formerly “Muli”) — commonly cited as a free alternative built in the same grotesque-geometric register as Proxima Nova. It is structurally closer to the specimen’s letterforms than Figtree in a few places (tighter apertures, slightly less rounded bowls), but its default weights render airier/thinner at small sizes.

Wordmark pairing: Mulish is a closer structural match to Proxima Nova itself (same lineage), but next to the heavy Montserrat wordmark its lighter default weight creates more visible weight-contrast than Figtree did — still a workable pairing, just a touch more “two different fonts” than Panel 1.

3 · All-Montserrat

font-family: "Montserrat", sans-serif;
Rendering: real Montserrat, loaded from Google Fonts (free, SIL OFL) — same face as the wordmark, at a lighter weight for body copy.

The wordmark is already bold Montserrat per PRD FR-45/46 — this panel asks what happens if the rest of the UI matches it too, at 500–600 weight for body/labels instead of the wordmark’s 700–800.

Wordmark pairing: wordmark and body are now the same face at different weights (700 vs 500) — the most cohesive-looking panel, but risks monotony: every heading, label and caption starts to look like it wants to be the wordmark, and Montserrat’s geometric letterforms are noticeably less neutral at small caption sizes than a body-purpose-built face.

4 · SF Pro / system-ui

font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui, sans-serif;
Rendering: your OS's native UI font (SF Pro on macOS/iOS) — no webfont load at all.

Apple-native baseline, since the user named Meta’s Muse and Apple’s own apps as inspiration. This is the “free, zero-load, matches the OS chrome” option.
